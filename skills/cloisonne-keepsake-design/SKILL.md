# 掐丝珐琅纪念品设计

把用户提供的照片转译成具有真实金属掐丝、烧制珐琅和完整产品结构的纪念品成品摄影图。交付重点是“可制造感的实体产品”，不是给原照片添加滤镜，也不是把照片平面印刷到挂件上。

## 适用边界

使用本 Skill：

- 用户提供人物、宠物、风景、合照或纪念照片，希望制成掐丝珐琅纪念品；
- 用户要求钥匙扣、冰箱贴、挂件、吊坠、徽章、纪念章或小型纪念牌的产品效果图；
- 用户希望比较同一照片的多种掐丝珐琅风格或产品载体。

不要使用本 Skill：

- 只想给照片添加普通珐琅滤镜，而不需要实体产品结构；
- 需要工厂可直接生产的 CAD、尺寸工程图、开模文件、报价或工艺证明；
- 需要普通亚克力、塑料、树脂、滴胶或平面印刷挂件；
- 只是在咨询掐丝珐琅历史、鉴定、修复或制作教学。

## 输入与最少提问

优先从用户请求和参考图片恢复：

- 参考照片及其角色：主体与构图参考、风格参考或待编辑对象；
- 产品载体；
- 风格预设；
- 金属颜色；
- 展示方式和背景；
- 输出数量；
- 是否先审核提示词。

缺少低风险选项时继续推进，使用默认值：

- 产品：钥匙扣；
- 风格：经典鎏金珠宝；
- 金属：抛光金色；
- 展示：暖象牙白摄影背景上的居中产品主图；
- 数量：1 张。

只有缺少参考图片、无法判断要保留的主体，或多个解释会明显改变最终产品时，才问一个最关键的问题。

## 模式选择

- **单款模式**：一个载体、一个风格、一个成品版本。默认使用。
- **风格对比**：同一载体生成多个有明确差异的珐琅风格版本。
- **产品系列**：同一照片生成钥匙扣、冰箱贴、挂件等不同载体。
- **提示词审核**：用户说“先看提示词”“生成前审核”时，只交付完整候选提示词，不调用图片生成工具。
- **模板套用**：用户要求“参考模板”“做成同款场景”或需要快速选择产品方向时，先读取 [模板库](references/templates/README.md)，再只读取选中模板。模板是构图和产品结构起点，不能覆盖用户参考图中必须保留的人物、宠物、姿态与场景。
- **工艺验证双视图**：用户要求检查厚度、边框或五金时，生成正面主图与一张侧角/微距概念图；这仍是视觉概念，不是工程证明。
- **打样沟通 Brief**：用户需要向工厂说明概念时，按 [非生产级打样 Brief](references/delivery-format.md#非生产级打样沟通-brief) 输出可讨论的载体、色区、五金与风险点；不输出 CAD、精确尺寸或可直接开模文件。

多版本请求必须逐个生成，每个版本单独指定载体、风格或展示差异；不要把同一提示词的随机结果冒充不同方案。

## 核心工作方式

1. **检查参考图。** 本地图片尚未显示在对话中时，先使用图片查看工具。明确每张图片是主体与构图参考、风格参考，还是编辑目标。
2. **锁定不变量。** 提取必须保留的人物或宠物特征、数量、姿态、表情、服饰、配饰、核心构图、主要场景和主色关系。不要擅自改变身份、人数或纪念意义。
3. **选择产品。** 用户指定时严格沿用；未指定时使用默认钥匙扣，或在构图明显更适合其他载体时简短说明推荐。复杂参考图先读取 [构图复杂度矩阵](references/composition-complexity.md)，再决定载体与简化方式。需要载体细节时读取 [产品预设](references/product-presets.md)；需要同类公开案例和提示词骨架时读取 [模板库](references/templates/README.md)。
4. **选择风格。** 用户指定时严格沿用；未指定时使用经典鎏金珠宝。需要多版本或具体风格差异时读取 [风格预设](references/style-presets.md)。
5. **形成生成规格。** 按“背景 → 产品 → 主体与场景 → 掐丝结构 → 珐琅材质 → 五金或背部结构 → 摄影方式 → 保留项 → 排除项”组织提示词。
6. **执行生成。** 正常图片任务优先使用内置图片生成工具。参考图是本地文件时，先确保工具能够看到该图片；需要保留人物时，明确锁定身份、体态、姿势和表情。工具不可用时只能交付提示词，并清楚标记“图片尚未生成”。
7. **检查并迭代。** 按 [质量检查表](references/quality-checklist.md) 检查输出。发现问题时一次只修一个主要缺陷，并在迭代提示词中重复关键不变量。
8. **保存交付。** 项目型任务把最终选中图保存到用户可访问的工作区，不覆盖原图或旧版本。报告文件路径、尺寸、最终模式、产品和风格，以及已验证和未验证事项。

## 生成规格不变量

每个版本必须同时满足：

- 画面是一件有真实厚度、边缘和结构的实体纪念品；
- 所有重要轮廓与内部色块由细致、连续、微微凸起的金属掐丝分隔；
- 掐丝内部是烧制后的珐琅釉料，具有玻璃光泽、轻微起伏、通透感和受控反光；
- 复杂照片可以合理简化成可读的珐琅分区，但必须保留主体身份、数量、姿态和核心场景；
- 产品载体对应的五金、磁吸或背部结构必须完整、合理、可见或能被摄影角度可信地解释；
- 产品摄影应有完整轮廓、清晰细节、合理阴影和真实金属反射；
- 不添加未经要求的文字、品牌、人物、装饰或叙事元素。

必须排除：

- 平面印刷照片、贴纸、树脂滴胶、亚克力、塑料和廉价纪念品质感；
- 只有金色描边但没有真实金属高度与珐琅分区；
- 五金断裂、挂孔悬空、磁吸结构不合理、产品被裁切；
- 人物数量变化、身份漂移、肢体异常、核心姿态或场景丢失；
- 水印、乱码、无关文字和品牌标识。

## 结果说明

除非用户只要提示词，按 [结构化交付格式](references/delivery-format.md#标准交付格式) 说明：

- **设计选择**：载体、外轮廓、风格、金属与展示方式；
- **保留项**：已锁定的主体、数量、姿态、场景和色彩关系；
- **简化项**：为适配掐丝分区而有意归并的细节；
- **图片生成状态**：已生成、失败或工具不可用；
- **技术状态**：已实际核验的格式、尺寸和保存路径；
- **视觉 QC**：参考图保留、工艺辨识、产品结构、摄影质感的检查结论；
- **未验证边界**：这是产品概念摄影图，不证明真实工厂能够按图直接生产。

不要把“生成成功”写成“已经可以投产”。

## 隐私与发布

- 不把用户参考照片、生成结果或私人路径固化进 Skill 文件、示例或公开仓库；
- 不上传、公开或分享用户图片，除非用户明确授权具体目标；
- 公开 Skill 只包含通用规则、预设、检查标准和非可识别的模板预览；模板不能暗示或复刻某位真实用户的身份。
