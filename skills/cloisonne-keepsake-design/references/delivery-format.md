# 交付格式

只在生成、提示词审核、方案系列或打样沟通中读取本文件。不要把未执行的图片生成、未读取的文件尺寸或未完成的视觉检查写成已完成。

## 标准交付格式

```markdown
### 设计选择
- 输入模式：参考图 / 纯文字 / 参考图加文字
- 风格与子预设：
- 输出形式：实体纪念品 / 单幅艺术图
- 载体与结构，或画布与构图：
- 展示方式：

### 保留或约束项
- 图片路线需要保留，或纯文字路线必须满足的主体、数量、姿态、服饰/特征：
- 核心场景、构图与色彩：

### 简化或补齐项
- 为适配风格而归并的细节，或纯文字路线补齐的低风险设计假设：

### 图片生成状态
- 已生成 / 未生成 / 工具不可用：

### 技术状态
- 仅列出实际核验过的格式、尺寸、文件路径或工具限制：

### 视觉 QC
- 输入一致性：
- 风格辨识：
- 输出形式一致性：
- 整体质感：

### 未验证边界
- 实体产品图不是 CAD、量产图、报价或生产证明；艺术图不代表真实原作媒介已经制作。
```

如果用户只要提示词，保留“设计选择、保留或约束项、简化或补齐项和未验证边界”，并把图片生成状态明确写为“未调用图片工具”。单幅艺术图不输出工厂打样 Brief。

## 非生产级打样沟通 Brief

当用户要求“给工厂看看”“写个打样说明”时，输出以下信息用于沟通，不输出可直接开模的工程规格：

```markdown
### 概念名称与输入角色
- 输入模式：参考图 / 纯文字 / 参考图加文字
- 图片与文字分别作为：主体/构图/色彩事实，或风格/形式/修改要求

### 产品概念
- 载体、外轮廓、建议展示面：
- 预期金属颜色与珐琅风格：
- 可见五金或背部结构：

### 画面分区重点
- 必须保留：
- 可由工艺师简化：

### 待工厂确认
- 实际尺寸、厚度、金属材质、色号、工艺可行性、背部结构、最小线宽、成本与交期。

### 边界
- 本 Brief 是视觉沟通稿；工厂应基于正式工程文件和实物打样确认量产方案。
```
