# 模板库

这些模板是可复用的“场景 + 产品结构 + 掐丝珐琅工艺”骨架，不是要求用户复刻预览图。使用时先保留用户照片中真正重要的人物、宠物、姿态、服饰和场景，再套用对应的产品形态与工艺要求。

公开预览只使用非可识别人物和通用场景，不含用户原图、姓名、地理位置或私人信息。

## 使用规则

1. 用户已指定载体或风格时，以用户要求为准；模板只补充构图和工艺细节。
2. 将模板中的 `【占位项】` 换成参考图中的实际信息，不要凭空补人、宠物、文字或品牌。
3. 公开发布案例前，确认有权发布参考图和生成结果；不要把用户原图加入本仓库。
4. 每次生成后按 [质量检查表](../quality-checklist.md) 逐级验收。
