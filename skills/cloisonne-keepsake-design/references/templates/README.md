# 模板库

这些模板是可复用的“参考图类型 + 风格 + 输出形式”骨架，不要求用户复刻预览图。使用时先锁定参考图中真正重要的人物、宠物、姿态、服饰、建筑和场景，再套用所选风格与输出结构。

公开预览只使用非可识别人物和通用场景，不含用户原图、姓名、地理位置或私人信息。

## 使用规则

1. 参考图是必需输入；缺图时先请求上传，不用模板预览替代用户内容。
2. 先选择风格，再选择输出形式。用户已指定其中任一项时，以用户要求为准。
3. 将模板中的 `【占位项】` 替换为参考图中的真实信息，不凭空补人、宠物、文字、品牌或地标。
4. 不跨风格偷换材质：极简纸感丙烯不默认加掐丝金线，掐丝珐琅也不默认变成纸张插画。
5. 公开发布案例前确认有权发布参考图和生成结果；不要把用户原图加入本仓库。
6. 每次生成后按 [质量检查表](../quality-checklist.md) 选择对应分支验收。
