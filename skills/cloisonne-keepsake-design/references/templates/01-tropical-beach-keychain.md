# 海岛旅行钥匙扣

![海岛旅行钥匙扣预览](../../assets/template-previews/01-tropical-beach-keychain.png)

## 适用

- 单人旅行照、海滩、礁石、悬崖、碧海或晴朗天空；
- 人物在水边站立、行走或面向海景的竖向构图；
- 希望把“旅途地点感”与人物纪念性同时保留。

## 产品设定

- 载体：拱门形竖向钥匙扣；
- 五金：顶部单一挂孔、一个连接环、闭合圆形钥匙圈；
- 风格：经典鎏金珠宝；
- 金属：抛光金色；
- 背景：暖象牙白棚拍背景。

## 可复制提示词

```text
将参考图中的【单人旅行主体】、【姿态和服饰】、【海滩与海水】、【两侧岩壁或悬崖】和【天空主色】转译为一枚真实的拱门形掐丝珐琅金属钥匙扣。保留主体数量、站位、动作和旅行场景的空间关系；复杂浪花和岩壁可简化成清晰的珐琅色块，但主体与地点必须可辨认。

使用圆润抛光金色外框，顶部单一挂孔、连接环和闭合钥匙圈全部完整入镜。人物、海浪、岩壁、云层与水面反光均以细致、连续、微凸的金色金属掐丝分隔；内部填充烧制后的玻璃质珐琅釉料，具有通透层次、轻微起伏和受控高光。暖象牙白摄影背景，居中产品展示视角，柔和高端棚拍光。

不要：平面照片印刷、亚克力、塑料、树脂滴胶、断裂五金、裁切钥匙圈、额外人物、文字、品牌、水印。
```

## 可调变量

- 主体居中且背景简单时，可把拱门改为包裹人物轮廓的异形钥匙扣；
- 日落场景可改为复古铜胎珐琅，但岩壁和海水的色块仍应清晰；
- 人物面积过小时，优先保留姿态与服饰轮廓，不强行还原面部细节。

## 验收重点

- 钥匙圈、挂孔和连接环闭合、比例合理；
- 海水、岩壁、天空由真实掐丝分区，不是平面插画；
- 人物和地貌之间的原始构图关系仍能识别。
