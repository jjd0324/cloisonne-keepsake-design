# 展示形式

风格选定后读取本文件。展示形式只决定设计如何呈现，不定义 Junda Visual Craft 的能力边界，也不应偷偷改写用户选定的风格。

## 载体应用效果图

适用于手机壳、钥匙扣、冰箱贴、包挂、手机挂件、吊坠、徽章、装饰挂件、纪念牌、包装及其他用户指定载体。

- 读取 [载体预设](product-presets.md)，使用与目标载体一致的外轮廓、开孔、边缘、厚度、五金、磁吸或支撑结构；
- 以可信的产品展示视角完整呈现载体，结构不裁切、不悬空、不混用；
- 视觉风格与真实制造材料分开判断：掐丝珐琅可以是真实珐琅结构，也可以作为手机壳、包装等表面的装饰嵌片或视觉语言；没有生产证据时不得宣称整件载体由该工艺制成；
- 极简纸感丙烯作为表面视觉时，纸张纹理不能看成会脱落的真实纸片，也不要自动加入珐琅金丝；
- 极简低多边形编辑插画作为载体表面的二维视觉时，小尺寸载体减少切面并放大主体；载体本身保持真实结构，不做成 3D 多面体模型；
- 载体没有现成预设时，只补齐该物件必需且可见的结构，并把材料、厚度与生产方式标为待确认，不强行套成钥匙扣或纪念牌。

## 独立视觉图

适用于艺术图、封面、海报、壁纸，以及“只生成一张图片”“不要产品结构”等请求。

- 画布本身就是最终输出，不出现未经要求的钥匙圈、挂孔、吊链、磁吸、底座、商品外壳、手持展示或棚拍结构；
- 用户指定比例与用途时沿用；未指定时，有参考图则根据原图构图选择，纯文字则根据主体与场景选择方形、4:5 竖幅或 3:2 横幅；
- 封面或海报需要文案时，只使用用户确认的准确文字，并为标题、人物和平台裁切预留安全区；未提供文字时不自行编写标题；
- 掐丝珐琅风格可做成满画幅珐琅艺术面，保留金属分区与玻璃釉面，但不要自动变成挂件或挂牌；
- 极简纸感丙烯风格以粗糙白纸为完整画面，大留白是构图的一部分；
- 极简低多边形编辑插画默认以纯色画布为成品，把场景居中收束并自然收边；不要保留照片矩形框、装饰背景或 3D 展台；
- 独立视觉图仍需按所选风格提炼图片内容或落实文字规格，不退回普通照片滤镜。

## 对比输出

用户需要比较时，可使用以下两种清晰组合：

1. **同风格、不同形式**：例如同一风景分别生成极简纸感丙烯封面与同风格手机壳效果图。
2. **同形式、不同风格**：例如同一图片或文字主题分别生成掐丝珐琅、极简纸感丙烯与极简低多边形编辑插画的独立视觉图。

每个版本单独生成与保存，命名中同时包含风格和展示形式。不要用一张分屏拼贴代替独立成品，除非用户明确要求对比板。
