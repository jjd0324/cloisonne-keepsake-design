# 模板库

这些模板是可复用的“内容类型 + 风格 + 展示形式”骨架，不要求用户复刻预览图。它们支持参考图、纯文字、参考图加文字三种入口：图片路线先锁定可见事实，纯文字路线先锁定明确描述，再套用所选风格与展示结构。

公开预览只使用非可识别人物和通用场景，不含用户原图、姓名、地理位置或私人信息。

## 使用规则

1. 参考图不是必需输入；接受参考图、明确文字描述或两者组合。只有图片和可执行文字主题都缺失时，才请求用户任选一种方式补充内容。
2. 先选择风格，再选择展示形式。用户已指定其中任一项时，以用户要求为准。
3. 将模板中的 `【占位项】` 替换为图片中的可见事实或文字中的明确要求。纯文字路线可补齐低风险的构图与光线，但必须说明假设，不凭空补真实身份、品牌、准确地标或事实性文字。
4. 最终提示词只保留当前输入分支：图片路线写图片不变量，纯文字路线写文字约束，混合路线写图片事实与明确修改；不要把模板中的条件说明原样交给图片模型。
5. 不跨风格偷换材质：极简纸感丙烯不默认加掐丝金线，掐丝珐琅也不默认变成纸张插画。
6. 公开发布案例前确认有权发布输入与生成结果；不要把用户原图或私人文字内容加入本仓库。
7. 每次生成后按 [质量检查表](../quality-checklist.md) 选择对应分支验收。
