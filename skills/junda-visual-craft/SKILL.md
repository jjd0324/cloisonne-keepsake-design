# Junda Visual Craft

这是 Junda 品牌下的风格化视觉设计 Skill。先从参考图、文字描述或两者组合建立内容规格，再分别选择**视觉风格**与**展示形式**，最后生成可检查的图片。风格决定画面语言与工艺质感；展示形式决定设计是独立画面，还是应用到某种实体载体。钥匙扣、冰箱贴、手机壳、挂件和封面都只是可扩展的展示形式，不是能力边界。

## 输入模式与选择顺序

固定顺序如下：

1. **识别输入模式**：接受三种入口：上传参考图、只提供明确文字描述、参考图加文字补充。图片与文字都没有，或文字没有说明任何主体/场景主题时，只请求用户“上传参考图，或用文字描述想生成的内容”。
2. **建立内容规格**：图片输入提取主体数量、身份特征、姿态、服饰、核心轮廓、空间关系、地点锚点与主色；纯文字输入把用户明确写出的主体、数量、动作、场景、构图、颜色和氛围作为约束；混合输入以图片为事实锚点，以文字指定风格、形式与明确修改。
3. **选择风格**：用户已指定时直接沿用；未指定时，从 [风格路由](references/style-presets.md) 给出简短选择。
4. **选择展示形式**：用户已指定时直接沿用；未指定时，从 [展示形式规则](references/output-formats.md) 选择独立视觉图或载体应用效果图。
5. **生成与视觉 QC**：按所选分支生成，使用对应检查项验收。

文字描述只要已经给出可执行的主体或场景主题，就不能再强制要求上传图片。纯文字输入中，允许补齐低风险的构图与光线细节，但要把关键假设写入生成规格；不得臆造真实人物身份、品牌、准确地标或具有事实含义的文字。

当内容已经明确，但风格和展示形式都未指定时，只问一个合并问题，同时给出两个维度的选项与一个基于当前内容的推荐组合。用户说“你决定”或“按推荐做”时直接推进。

## 风格与展示形式

### 风格

- **掐丝珐琅 / 景泰蓝**：以连续微凸金属掐丝、烧制珐琅色区、玻璃质釉面与真实金属反光为核心。需要生成时读取 [掐丝珐琅风格](references/styles/cloisonne-enamel.md)。
- **极简纸感丙烯**：以粗糙白纸、小主体、大留白、细而略不规则的手绘线与 2–4 种明确丙烯色块为核心。需要生成时读取 [极简纸感丙烯风格](references/styles/minimal-paper-acrylic.md)。
- **极简低多边形编辑插画**：以二维中大型几何光影切面、居中场景标本、纯色大留白与自然收边为核心。需要生成时读取 [极简低多边形编辑插画](references/styles/minimal-low-poly-editorial.md)。

先用 [风格路由](references/style-presets.md) 选风格，只读取当前选中的详细风格文件。除非用户明确要求混合风格，否则不要把金属掐丝与玻璃釉面、纸张纹理与丙烯平涂、二维几何切面混成一种含混材质。

### 展示形式

- **载体应用效果图**：把所选风格应用于手机壳、钥匙扣、冰箱贴、包挂、吊坠、徽章、纪念牌、包装或其他用户指定载体。读取 [展示形式规则](references/output-formats.md) 和 [载体预设](references/product-presets.md)，只表现该载体真正需要的轮廓、开孔、边框、五金、磁吸或支撑结构。
- **独立视觉图**：输出一张完整风格化艺术图、封面、海报或壁纸，不出现未经要求的商品外壳和产品摄影结构。读取 [展示形式规则](references/output-formats.md)；画面比例、构图和文字安全区由具体用途决定。

“生成一张图片”“只要画面”“做成封面”默认理解为独立视觉图；“应用到手机壳”“做成钥匙扣/冰箱贴/徽章”等默认理解为载体应用效果图。载体没有现成预设时，按它真实可见的结构建立新规格，不强行套成最接近的纪念品。

## 运行模式

- **单方案**：一个风格 × 一个展示形式。默认使用。
- **风格对比**：同一内容规格、同一展示形式，生成多个明确不同的风格版本。
- **形式对比**：同一内容规格、同一风格，分别生成独立视觉图与载体应用效果图。
- **方案矩阵**：用户明确要求时，组合多个风格与多个展示形式；每个组合单独生成、命名和验收。
- **提示词审核**：用户说“先看提示词”或“生成前审核”时，只交付完整候选提示词，不调用图片生成工具。
- **模板套用**：需要快速选择方向时，先读取 [模板库](references/templates/README.md)，再只读取选中的模板。模板不能覆盖图片事实或文字中的明确约束。
- **载体结构双视图**：仅用于载体应用效果图。用户要求检查厚度、边框、开孔或五金时，生成正面主图与侧角/微距概念图；这仍不是工程证明。
- **打样沟通 Brief**：仅用于实体载体。按 [非生产级打样 Brief](references/delivery-format.md#非生产级打样沟通-brief) 输出讨论材料，不提供 CAD、精确尺寸或可直接开模文件。

多版本请求必须逐个生成。每个版本都要写清风格、展示形式与实质差异，不要把同一提示词的随机结果冒充不同方案。

## 工作流程

1. **识别并检查输入。** 有图片时，若本地图片尚未显示在对话中，先使用图片查看工具，并标记其是主体与构图参考、风格参考，还是待编辑对象；只有文字时，直接解析文字，不要求补图。
2. **锁定内容规格。** 图片或混合输入提取必须保留的信息，并指出哪些细节可以简化；纯文字输入列出明确约束与必要假设。人物、宠物、建筑被遮挡时，不臆造缺失身份特征。
3. **评估复杂度。** 多主体或复杂场景读取 [构图复杂度矩阵](references/composition-complexity.md)，决定信息优先级；它只能指导简化，不能擅自改变用户指定的风格或载体。
4. **确定风格与形式。** 先选风格，再选展示形式。未指定且用户没有授权自行决定时，给出推荐与简短菜单后等待选择。
5. **形成生成规格。** 按“输入模式与内容规格 → 图片不变量或文字约束 → 风格规则 → 展示形式结构 → 构图与背景 → 保留项 → 简化项/合理补齐项 → 排除项”组织提示词。最终交给图片模型的提示词只保留当前输入分支，不照抄模板中的条件说明。
6. **执行生成。** 正常图片任务优先使用内置图片生成工具。图片路线需要保留人物时，明确锁定身份、体态、姿势和表情；纯文字路线不得声称保留了未提供的参考图细节。工具不可用时只交付提示词，并标记“图片尚未生成”。
7. **检查并迭代。** 按 [质量检查表](references/quality-checklist.md) 选择对应风格与展示形式的检查项。一次只修一个主要缺陷，并在迭代提示词中重复关键不变量。
8. **保存交付。** 项目型任务把最终选中图保存到用户可访问的工作区，不覆盖原图或旧版本。报告路径、尺寸、风格、展示形式、已验证项与未验证项。

## 共通输入一致性

每个版本都必须满足：

- 图片或混合输入：参考图中的主体数量、核心姿态、动作方向、主要服饰或物种特征、核心场景和空间关系仍可辨认；
- 纯文字输入：用户明确指定的主体、数量、动作、场景、构图、颜色和氛围得到落实，不声称存在或保留了参考图；
- 复杂输入可以简化，但简化规则必须符合所选风格，并说明被归并的次要信息；
- 不添加未经要求的人物、动物、文字、品牌、Logo、装饰或叙事元素；
- 画面完整入镜，无肢体异常、结构穿模、随机水印、乱码或无关签名；
- 生成成功不等于视觉通过，更不等于可直接生产。

### 掐丝珐琅分支

- 重要轮廓与内部色区由连续、清晰、微微凸起的金属掐丝分隔；
- 色区是烧制珐琅而非平面印刷、塑料、亚克力或树脂滴胶；
- 独立视觉图保留掐丝与釉面语言，但必须移除未经要求的商品外壳、五金和棚拍结构；
- 载体应用效果图必须使用与指定载体一致的边缘、开孔、厚度和连接结构；手机壳等不适合整块金属珐琅的载体，应表现为可信的装饰面、嵌片或视觉印制概念，不虚构已验证工艺。

### 极简纸感丙烯分支

- 以视觉提炼而非缩小写实为目标，保留最有辨识度的轮廓、动作和空间关系；
- 线条只辅助识别，少量明确丙烯色块承担主体表达；
- 独立视觉图以纸面本身为成品；封面用途需要尊重用户比例，并为准确文案预留安全区；
- 载体应用效果图把纸感丙烯作为表面视觉语言，纸张纹理是视觉效果而非脆弱的真实纸片；不得默认加入掐丝与玻璃釉面。

### 极简低多边形编辑插画分支

- 使用中大型二维几何色面概括真实结构和光影，不使用密集碎三角、机械滤镜或 3D 低模建模；
- 图片路线保留主体身份锚点、姿态、服饰、原图方向、透视和场景关系；纯文字路线落实已写明的主体、动作、环境、构图与色彩；
- 独立视觉图默认把完整场景收束为居中的小型视觉标本，沿人物、地形或建筑自然收边，四周使用大面积单一纯色留白；
- 载体应用效果图只把低多边形作为表面二维视觉，小尺寸载体减少切面并放大主体，不把载体本身做成 3D 多面体；
- 不混入粗糙纸纹、丙烯笔触、金属掐丝、玻璃釉面、粗黑描边或装饰性渐变背景。

## 结果说明

除非用户只要提示词，按 [结构化交付格式](references/delivery-format.md#标准交付格式) 说明：

- **设计选择**：风格、展示形式、构图、载体或画布；
- **输入模式**：参考图、纯文字或参考图加文字；
- **保留/约束项**：图片路线锁定的主体、数量、姿态、场景和色彩关系，或纯文字路线必须满足的描述；
- **简化/补齐项**：为适配所选风格而有意归并的细节，或纯文字路线中补齐的低风险设计假设；
- **图片生成状态**：已生成、失败或工具不可用；
- **技术状态**：实际核验的格式、尺寸和保存路径；
- **视觉 QC**：输入一致性、风格辨识、展示形式一致性和整体质感；
- **未验证边界**：实体产品图不证明工厂可直接生产，艺术图也不代表原作媒介已经真实制作。

## 隐私与发布

- 不把用户参考图、私人文字内容、生成结果或私人路径固化进 Skill 文件、模板或公开仓库；
- 不上传、公开或分享用户图片，除非用户明确授权具体目标；
- 公开模板只使用通用、非可识别的视觉原型，不复制外部作者原图、签名、水印或完整提示词；
- 对外发布前确认图片、人物、品牌与地点标识的权利边界。
